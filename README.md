# 安得

安得岗位千万件，<br>
大庇天下寒士俱欢颜。

免费、源码公开的公司官网工作收集器。目标是收集所有职业的岗位，让求职者按自己的关键词排序、查看完整 JD，并前往官网申请，而不是提供一个人的职业榜单。

[在线页面](https://nozomix1.github.io/wheres-my-job/) · [需求规格](SPEC.md) · [领域用语](CONTEXT.md) · [采集说明](crawler/README.md)

## 当前状态

新版页面已经迁入 `index.html`，无框架、无运行依赖。本地修改或 Git 提交不会自动更新在线站点；推送和部署需另行执行。

- 优先词加分、降权词扣分；关键词只改变顺序，不删岗位。标题／职责／要求每词分别计 `3 / 1 / 0.35`，同字段只算一次。降权力度暂定相同，净分可以为负；不是百分制，也不是录取概率。
- 命中词逐个显示出现次数，如 `Agent × 9`，一次只显示词；次数仅展示，不重复加分。官网明确提供的岗位职能类别显示在公司后，例如「字节跳动 · 后端」，不作为筛选或评分依据，缺失不猜测。
- 两组都空可按可靠官网日期浏览；未知日期放后。公司多选，招聘类型为全部／社招／校招／实习／人才计划，未知属性保守纳入但不冒充官网事实。
- 条件在本机保存，编辑后点击「查找岗位」才更新结果。示例仅在主动点击时追加，是旧 AI／Agent 方向的完整词汇示例，不是默认条件。结果连续加载，官网链接新窗口打开。
- 已断开并删除旧召回、Agent 判定、个人评分和重复 HTML 生成链。页面只读取独立岗位数据，旧脚本不能再覆盖首页。

## 本地查看与检查

直接打开 `index.html`，或用任意静态服务器提供仓库根目录；文件及 GitHub Pages 都不需要后端服务。

```sh
node tests/app.test.cjs
node tests/pipeline.test.cjs
node tests/feishu.test.cjs
node tests/feishu-classified.test.cjs
node tests/feishu-portals.test.cjs
node tests/moka-details.test.cjs
node tests/moka-list-jd.test.cjs
node tests/beisen.test.cjs
node tests/beisen-portals.test.cjs
node tests/beisen-evidence.test.cjs
node tests/jd-text.test.cjs
```

执行工具建议使用 **Node.js 22+**。已核验的十个飞书来源需已安装的 Chrome（可用 `CHROME_PATH` 指定）；其余 custom 来源的平台路径与鉴权仍需按来源配置；没有统一承诺所有来源即装即用。

## 更新数据

```sh
# 唯一主入口：尝试采集后安全发布数据，不重建 HTML
node crawler/update.js

# 也可只更新指定来源；key 来自 crawler/sites.json
node crawler/update.js stepfun stepfun_social

# 分开执行：采集候选／完整成功快照 → 发布
node crawler/crawl.js stepfun
node crawler/crawl.js stepfun_social
node crawler/publish.js stepfun stepfun_social
```

Windows 的 `crawler/run_daily.ps1` 仅转调同一主入口，不维护第二份站点清单。部分失败时命令返回非零；已验证完整成功的来源可更新，其余保留历史数据。缺目录、无已验证输入、失败、分页不完整或未知响应不得清空已发布岗位。详细输入契约与当前适配器限制见 [采集说明](crawler/README.md)。

本机成功快照放在被 Git 忽略的 `crawler/out/`；已发布数据为 `data/jobs.js`。目前未配置 Actions，快照也尚未接持久云端保存。以后定时任务以北京时间 08:00 **触发**为目标，不保证此时已完成。
